# alexdlp/tap

Homebrew formulae for my tools.

```bash
brew tap alexdlp/tap
brew install cinta
```

| Formula | What it is |
|---|---|
| [`cinta`](https://github.com/alexdlp/cinta) | Record, download and transcribe audio and video from the command line |

The formulae are written in each tool's own repository and copied here on release; changes
belong there.
